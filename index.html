🔌 Cómo habilitar la Depuración USB en Android

Sigue estos 3 sencillos pasos en tu teléfono antes de conectar por primera vez.

1

Activa las Opciones de Desarrollador

Abre Ajustes → Acerca del teléfono. Toca 7 veces continuas sobre el campo Número de compilación.

09:41 Ajustes
Modelo del dispositivo
Android 13 / 14
Número de compilación
Toca 7 veces seguidas
👈 Tocar 7x
✔ ¡Ahora eres desarrollador!
2

Habilita la Depuración USB

Regresa a Ajustes → Sistema → Opciones para desarrolladores. Busca e interrupta la casilla Depuración USB.

09:41 Opciones de desarrollador
Depuración USB
Modo de depuración cuando USB se conecta
Permanecer activo
Pantalla no se apaga cargando
3

Autoriza tu Computadora (RSA)

Conecta el cable USB. Aparecerá una ventana emergente en el teléfono. Acepta y marca la opción para recordar este equipo.

🎮 Controles remotos e instalación de APKs en MASV

Sin necesidad de tocar la pantalla del teléfono, MASV incluye un mando de controles rápidos vía ADB directamente en la pestaña Acciones:

🔊 Vol + 🔉 Vol - 🔇 Mute ⚡ Encender 🏠 Inicio ◀ Atrás 📑 Recientes 🔔 Notificaciones 📦 Instalar APK...

¿Cómo instalar aplicaciones (APK)?
• En MASV: Haz clic en el botón 📦 Instalar APK en dispositivo..., selecciona el archivo .apk de tu PC y se instalará automáticamente.
• En scrcpy: Durante una sesión activa, simplemente arrastra y suelta el archivo .apk sobre la ventana de scrcpy.

Requisitos previos del sistema

MASV utiliza adb y scrcpy como motor subyacente.

🐧 Linux (Debian/Ubuntu):

sudo apt install adb scrcpy

🪟 Windows (winget):

winget install Genymobile.scrcpy

🍎 macOS (Homebrew):

brew install scrcpy android-platform-tools
