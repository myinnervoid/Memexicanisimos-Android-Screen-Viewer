Requisitos previos

MASV necesita que adb y scrcpy estén instalados en tu sistema.

🐧 Linux (Debian/Ubuntu):

sudo apt install adb scrcpy

🪟 Windows (winget):

winget install Genymobile.scrcpy

🍎 macOS (Homebrew):

brew install scrcpy android-platform-tools

¿Webcam virtual en Linux? También necesitas: sudo apt install v4l2loopback-dkms
